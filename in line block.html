Important to learn inline-block

1. Understand `display` The most important property is display: inline-block; It tells the browser that an element should behave partly like an **inline** element and partly like a **block** element. 2. Know the difference You should understand these three: display: block; display: inline; display: inline-block; 3. Learn `width` and `height` With `inline-block`, you can control the size: css .box { display: inline-block; width: 200px; height: 150px; } 4. Learn `margin` and `padding` These are very important when creating boxes: css .box { margin: 10px; padding: 20px; } *Margin = space outside the box. *Padding = space inside the box. 5. Learn border For example: css border: 2px solid black; This creates a 2-pixel black border around the element. 6.
